*[SMTP]: Simple Mail Transfer Protocol — the standard protocol for sending email between servers
*[IMAP]: Internet Message Access Protocol — lets email clients read messages while keeping them on the server
*[POP3]: Post Office Protocol v3 — downloads email to your device and typically removes it from the server
*[MTA]: Mail Transfer Agent — software that routes and delivers email (e.g., Postfix)
*[MDA]: Mail Delivery Agent — software that stores email in a user's mailbox (e.g., Dovecot)
*[MUA]: Mail User Agent — the email client used to read and compose email (e.g., Thunderbird)
*[SPF]: Sender Policy Framework — a DNS record that declares which servers can send email for your domain
*[DKIM]: DomainKeys Identified Mail — cryptographic signatures proving an email wasn't altered in transit
*[DMARC]: Domain-based Message Authentication, Reporting & Conformance — policy for handling emails that fail SPF/DKIM
*[TLS]: Transport Layer Security — encryption for data in transit (the "S" in HTTPS)
*[SSL]: Secure Sockets Layer — predecessor to TLS, often used interchangeably (technically deprecated)
*[SASL]: Simple Authentication and Security Layer — a framework for adding authentication to protocols
*[MIME]: Multipurpose Internet Mail Extensions — the standard for email attachments and HTML content
*[MX]: Mail Exchange — a DNS record that tells other servers where to deliver email for your domain
*[PTR]: Pointer Record — a reverse DNS record mapping an IP address back to a hostname
*[DNSBL]: DNS-based Blackhole List — a list of IP addresses known to send spam
*[ACME]: Automatic Certificate Management Environment — the protocol used by Let's Encrypt
*[SNI]: Server Name Indication — a TLS extension allowing multiple SSL certs on one IP address
*[LMTP]: Local Mail Transfer Protocol — used to deliver mail from Postfix to Dovecot
*[JWT]: JSON Web Token — a compact way to securely transmit information between parties
*[HMAC]: Hash-based Message Authentication Code — a way to verify both data integrity and authenticity
*[RAG]: Retrieval-Augmented Generation — combining search with AI to provide contextual answers
*[API]: Application Programming Interface — a way for programs to talk to each other
*[REST]: Representational State Transfer — an architectural style for web APIs using HTTP methods
*[CRUD]: Create, Read, Update, Delete — the four basic operations on data
*[ORM]: Object-Relational Mapping — a technique that lets you query databases using programming objects
*[CORS]: Cross-Origin Resource Sharing — a security mechanism controlling which websites can call your API
