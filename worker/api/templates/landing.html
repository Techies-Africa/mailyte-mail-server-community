Mailyte Email Server

Self-hosted email infrastructure built on Postfix, Dovecot, and Rspamd. Full SMTP, IMAP, POP3 with tracking, webhooks, and a REST API.

Production-grade mail server with developer-first APIs
✉

SMTP Server (Postfix)

Send and receive email. TLS/STARTTLS on ports 25, 587, 465. SASL authentication, virtual domains, relay controls.

📥

IMAP & POP3 (Dovecot)

Full mailbox access on ports 993/995. Maildir storage, quota enforcement, SSL/TLS, ManageSieve support.

🛡

Spam Filtering (Rspamd)

Machine-learning spam detection, greylisting, DNSBL checks, content filtering, virus scanning.

📈

Email Tracking

Open tracking via invisible pixel. Click tracking via URL rewriting. Real-time engagement data.

🔌

Webhooks

50+ event types: delivered, bounced, opened, clicked, auth failures. HMAC-SHA256 signed payloads with retry.

⚙

REST API

Full CRUD for domains, mailboxes, aliases, filters, SSL certificates. OpenAPI 3.0 spec with Swagger UI.
